# Telecommunication Systems Project

This project was done for the course Telecommunication Systems II (Aristotle University of Thessaloniki)

The project is based on the following paper:

*N. Nartasilpa, A. Salim, D. Tuninetti and N. Devroye, "Communications System Performance 
and Design in the Presence of Radar Interference," in IEEE Transactions on Communications, vol. 
66, no. 9, pp. 4170-4185, Sept. 2018, doi: 10.1109/TCOMM.2018.2823764.*

The objective was to reproduce the simulation results presented in Section II of the paper, where the effect of radar interference on a single-carrier 
communication system is studied. More specifically:
- to implement the simulation framework described in Section II
- to verify the published numerical results and compare our findings with those presented in the paper
